## 端口速率、月流量、线路：三个别混着看

1Gbps 是端口速率，回答的是“瞬时最高能跑多快”；月流量是配额，回答的是“一个月总共能搬多少数据”；线路是路径，回答的是“这些数据走哪条路回国”。三者对体验的影响完全不同，按重要程度排，对大多数人是流量 > 线路 > 端口。

先说流量。1Gbps 跑满约 125MB/s，一小时能搬走 450GB 左右。3TB 月流量的档位，理论上满速跑不到 7 小时就用光了；20TB 的顶配也就 45 小时。也就是说，除非你一个月只集中传几次大文件，否则先到顶的一定是流量，不是端口。选档时按“每天大概传多少 GB”去估算，比盯着 1Gbps 有用。

再说线路。这批特价属于普通国际网络产品，官方没有为它公开中国优化线路的测试信息。机房可选洛杉矶、圣何塞、西雅图、达拉斯、芝加哥、纽约、阿什本、亚特兰大，以及阿姆斯特丹、法国、都柏林等欧洲节点，具体某个套餐能选哪些机房要看下单页的实时库存。国内访问想稳一点，选洛杉矶或圣何塞通常在物理距离上更占便宜，但别指望这类特价档有专线级的晚高峰表现。

端口速率放在最后看。1Gbps 在 2026 年的低价 VPS 里已经算标配，它决定的是单次大文件传输、镜像拉取、备份上传的上限速度，不决定晚八点你打开网页要等几秒。

## 常见问题

**1Gbps 真的能跑满吗？**
端口上限是 1Gbps，实际速度取决于对端、路由和同时段的其他用户。跨国传输能跑到多少，跟机房位置、目标服务器、时段都有关系，没有统一的答案。买之前可以先用自己常用的目标站点做一次路由测试。

**续费会涨价吗？**
年付套餐按官网当时标价续费，下单页会写明续费金额。RackNerd 的促销档位本身是轮换的，同一档配置不同批次价格可能不一样，但已经开通的机器续费按订单里的价格执行。

**面板是什么？**
自研的 ctrl 面板，早期用的是 SolusVM。ctrl 里能开关机、重装系统、开 HTML5 VNC、重置 root 密码、查看流量、设置入站防火墙规则，还有一键应用区，OpenClaw、Ollama + Open WebUI、n8n、Portainer、Coolify、CyberPanel、CloudPanel 这类都能直接部署。

**能装 Windows 吗？**
官方模板是 Linux 发行版，需要 Windows 得自己准备授权并通过工单申请自定义 ISO，不提供现成的 Windows 模板。
